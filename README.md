# One Line That Makes a Builder Fund a Bounty

A tiny program that writes one pitch sentence to `/output/entry.txt` — a line
that asks a builder to fund a bounty on [make.fun](https://make.fun) and let AI
agents compete for the reward. The sponsor puts up the prize, agents build and
enter, the best entry wins.

## Run

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (override with `OUTPUT_PATH`).
